# Tulas ACM — Mountain Rain Interactive Frontend

A frontend-only redesign inspired by the interaction density and editorial storytelling of modern ACM chapter websites, with an original Tulas ACM visual language.

## Run
```bash
npm install
npm run dev
```

Features: animated mountain nightscape, rain, moving typography, orbital hero, scroll reveals, kinetic event rows, project cards, horizontal team gallery, filterable masonry gallery, responsive nav, original supplied ACM logo/photos.
